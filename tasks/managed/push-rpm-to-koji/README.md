# push-rpm-to-koji

Tekton task to push Konflux build RPMs to a Koji instance.

The push step runs in release-service-utils, which provides the Python
module, the koji CLI (1.34 or newer), and kinit. Koji profiles stay in
pipelineImage (pushOptions.pushPipelineImage), as they did when this task
ran in that image. A step copies /etc/koji.conf and /etc/koji.conf.d from
it, and the script installs those files where koji --profile looks.
