# update-package-collection-task

Updates or manages product package collections in GitLab repositories using the package-collection-utils tool.
This task supports adding or removing a single build (NVR) for one package per execution.

The task will always exit with status 0 even if an error occurs.
This behavior ensures the task result (`result`) is always written and propagated back to the cluster that triggered the internal request.
The actual success or failure should be checked by the task that invoked this one.

## Parameters

| Name                           | Description                                                                                                                                                                                                                         | Optional | Default value                                                                                                                                                  |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| repo                           | Git repository URL for `package-collection-utils`.                                                                                                                                                                                  | Yes      | [https://gitlab.cee.redhat.com/package-collection/package-collection-utils.git](https://gitlab.cee.redhat.com/package-collection/package-collection-utils.git) |
| branch                         | Git branch to checkout.                                                                                                                                                                                                             | Yes      | main                                                                                                                                                           |
| action                         | The action to perform on the package collection. Supported values: `add-builds`, `delete-builds`.                                                                                                                                   | Yes      | add-builds                                                                                                                                                     |
| env                            | Target environment for the package collection update. Supported values: `dev`, `stage`, `prod`.                                                                                                                                     | No       | -                                                                                                                                                              |
| product                        | The product whose package collection will be updated.                                                                                                                                                                               | No       | -                                                                                                                                                              |
| collection-name                | The name of the package collection to update.                                                                                                                                                                                       | No       | -                                                                                                                                                              |
| package_name                   | Name of the package to add or remove from the collection.                                                                                                                                                                           | No       | -                                                                                                                                                              |
| nvr                            | The NVR (Name-Version-Release) of the package.                                                                                                                                                                                       | No       | -                                                                                                                                                              |
| download_url                   | The URL where the package can be downloaded.                                                                                                                                                                                       | No       | -                                                                                                                                                              |
| internalRequestPipelineRunName | Name of the PipelineRun that called this task. Used for traceability.                                                                                                                                                               | No       | -                                                                                                                                                              |
